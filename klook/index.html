클룩 할인코드 입력 방법

입력 방식은 결제 화면에 바로 넣기와 '내 쿠폰'에 먼저 등록하기 두 가지입니다.

앱 결제 화면에서 클룩 할인코드 넣기

  1. 할인 링크로 클룩 앱 열기

    아래 버튼으로 접속한 뒤 앱으로 이동해 로그인합니다. 첫 결제 할인코드는 앱 로그인 상태에서만 확인됩니다.

  2. 패키지·날짜·인원 선택

    상품 옵션과 이용일, 인원을 고르면 결제 금액이 정해집니다. 최소 결제 금액 조건은 이 합계로 판정됩니다.

  3. 예약자 정보 입력 후 결제 화면 이동

    여권 영문명 등 필수 정보를 채우면 결제 화면이 열립니다.

  4. 할인코드 입력란에 붙여 넣기

    대문자·숫자 그대로 넣고 적용을 누릅니다. 할인액이 결제 요약에 줄로 표시되는지 확인합니다.

  5. 결제수단 선택 후 최종 금액 확인

    결제수단 조건이 있는 할인코드는 이 단계에서 할인이 유지되는지 다시 봅니다.

'내 쿠폰'에 클룩 할인코드 등록해 두기

  1. 앱 계정 메뉴의 '내 쿠폰' 열기

    할인코드 등록 칸에 문자열을 넣으면 쿠폰함에 쿠폰으로 저장됩니다.

  2. 결제 화면에서 쿠폰 선택

    등록한 할인코드가 사용 가능한 쿠폰 목록에 뜨면 골라서 적용합니다. 목록에 없다면 이 예약이 조건에 맞지 않는다는 뜻입니다.

💡 알아두세요: 선착순 KKPJPHOT4M은 목요일 오전 10시에 미리 '내 쿠폰'에 등록해 두면 결제 도중 수량이 끝나는 상황을 줄일 수 있습니다.
