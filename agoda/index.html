아고다 할인코드 적용 순서

전용 링크로 들어온 뒤 결제 화면에 닿기까지 접속 경로를 바꾸지 않는 것이 핵심입니다.

  1. 할인코드 발급 버튼으로 아고다 접속

    전용 링크 경유가 필요한 할인코드가 대부분이라 검색창이나 즐겨찾기로 들어가면 입력해도 거절될 수 있습니다. 웹 전용 할인코드는 PC 또는 휴대폰 브라우저로 여세요.

  2. 아고다 계정 로그인

    신규회원 할인코드는 가입 직후 예약 이력이 없는 계정에서만 통과하므로, 로그인한 계정이 맞는지 먼저 확인하세요.

  3. 숙소 검색과 날짜·인원 입력

    체크인·체크아웃 날짜와 객실 수를 넣고 숙소를 고릅니다. 국가 제한이 있는 할인코드라면 숙소 주소의 나라를 이 단계에서 확인하세요.

  4. 할인코드 적용 가능 요금 선택

    같은 객실이라도 요금마다 할인코드 적용 여부가 다릅니다. 할인코드 적용 가능 표시가 있는 요금을 고르세요.

  5. 예약자 정보 입력 후 결제 화면 이동

    투숙객 이름과 연락처를 채우면 결제 단계로 넘어갑니다.

  6. 할인코드 입력란에 붙여 넣기

    결제 화면의 할인코드 입력란에 문자열을 그대로 넣고 적용을 누르세요. 대소문자와 숫자를 바꿔 쓰면 인식되지 않습니다.

  7. 요금 요약에서 할인 금액 확인 후 결제

    요금 요약에 할인 줄이 생기고 총액이 줄었는지 본 뒤 결제수단을 고르세요. 할인 줄이 없으면 결제 전에 아래 해결 방법부터 확인하세요.

아고다 앱에서 할인코드 넣는 순서

앱 전용 할인코드는 1번 단계가 다릅니다. 아고다 앱을 열어 로그인한 뒤 숙소를 고르고, 결제 화면 할인코드 입력란에 AGODADEAL8 또는 AGODADEAL5를 넣으면 됩니다. 앱은 웹 전용 링크를 거치지 않으므로 웹 할인코드와 섞어 시도하지 마세요.

💡 알아두세요: 예약 1건에는 할인코드 1개만 들어갑니다. 두 번째 할인코드를 넣으면 앞의 할인코드가 바뀌므로 할인액이 큰 쪽 하나만 남기세요.
